# 🧮 Calculadora Azul

Uma calculadora web simples, funcional e estilizada em tons de azul.

## 📋 Sobre

Calculadora básica com interface gráfica desenvolvida em HTML, CSS e JavaScript puro. 
Projeto criado para praticar lógica de programação e estilização CSS.

## ✨ Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão (com proteção contra divisão por zero)
- 🧹 Botão para limpar (C)
- 🎨 Interface em tons de azul

## 🚀 Como usar

1. Salve o código como `calculadora.html`
2. Abra o arquivo em qualquer navegador moderno
3. Clique nos botões para fazer cálculos

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)
